# Play Off！
![Play Off! ロゴ](./image/Icon.svg)

気軽にゲームをPlay！
## 概要
Play Off！はブラウザで遊べるゲームを集めています。
ブラウザからすぐにアクセスでき、軽い動作を目指しています。  
## 特徴
* ホスティングのしやすさ:Renderなどでの静的サイトでのデプロイに対応。  
* カテゴリ別での表示:目的のジャンルごとでゲームを探せる。  
* 非営利運営:利益を目的とせず、誰もがゲームを楽しめる場所を目指しています。
